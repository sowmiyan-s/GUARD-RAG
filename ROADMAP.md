# GuardRAG Development Roadmap

## 🎯 Vision

Make privacy-first, offline AI document intelligence accessible to every organization, regardless of size or technical expertise.

## 📅 Timeline

### Q3 2026 (Current)

✅ **Completed**
- Core RAG with Ollama integration
- 4-tier safety guardrails
- Web UI and CLI
- Multi-device LAN sharing
- Comprehensive documentation

🔄 **In Progress**
- Performance optimization
- Extended language support
- Additional model integrations

📋 **Planned**
- Community feedback integration
- Enterprise feature enhancements

#### Features
- [ ] **Qdrant Vector Store Support** — Alternative to FAISS for better scalability
- [ ] **Multi-Language OCR** — Support for scanned documents in 20+ languages
- [ ] **Real-time Collaboration** — Multi-user document annotation and Q&A
- [ ] **Advanced Analytics Dashboard** — Insights into document usage patterns
- [ ] **Custom Model Fine-tuning** — Fine-tune models on your data
- [ ] **API Rate Limiting** — Configurable per-user/per-key limits
- [ ] **Knowledge Graph Extraction** — Auto-extract relationships and entities

#### Infrastructure
- [ ] **Helm Charts** — Easy Kubernetes deployment
- [ ] **AWS/Azure/GCP Templates** — One-click cloud deployment
- [ ] **High Availability Setup** — Multi-node clustering
- [ ] **Database Migration Tools** — Easy upgrades
